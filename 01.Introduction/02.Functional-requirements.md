# Functional Requirements

- Functional requirements define what a system should do — the features it provides and how users interact with them.
- Describe what users can do with the system.

## Example 

Build a chat application. That's not a requirement. That's a vague idea because it does not describe what users can do with the system.

- Users should be able to sign up and log in to their accounts.
- Users should be able to search for other users and start a conversation.
- Users should be able to send and receive messages in real time.
- Users should be able to view their chat history.
- Users should be able to see whether a message has been delivered and read.
