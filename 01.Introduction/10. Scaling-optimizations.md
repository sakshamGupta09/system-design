# Step 4: Scaling & Optimization

## 1. Identify Bottlenecks

Review your design and identify which components will struggle as traffic increases?

- What happens during traffic spikes?
- Timeline generation for users with many followers.
- Media upload and storage costs.

## 2. Scale and Optimize for each bottleneck identified

| Problem | Possible Solution |
|---|---|
| Too many requests on a few servers | Horizontal scaling + load balancing |
| Slow, repeated database reads | Caching + indexing |
| Database cannot handle the workload | Query optimization, replication, or sharding |
| Slow background tasks | Message queues + asynchronous processing |
| Large media files are expensive to deliver | Object storage + CDN + compression |
