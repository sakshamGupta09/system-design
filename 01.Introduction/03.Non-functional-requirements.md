# Non Functional Requirements

- Not what the system does but how well it does it.

## Most important NFRs

1. Perfromance How fast your system responds. Measured in respons etime or latency
2. Scalability System should be able to handle increased load gracefully.
3. Availability How often the system is operational Expressd in nines.99.9 or 99.999% Availabity.99% Two 99s means 3.65 days downtime per yesr. 99.9% 3 9s means 8.76 hours of downtime per year. 99.99 4 9s means 52 minutes downtime per year. 5 9s means 5 minutes of downtime per year.

## Example

FR can be that a user should be able to upload images. NFR would be -

- Performance System should upload an image of size 200MB within 3 seconds on standard broadband connection.
- Scalability System should be able to handle 500 million image uploads per day.
- Reliability Images should never be lost once uploaded.
- Availability System should be up 99.9% of the time.
