# Document Databases

## Key Strengths

1. **Flexible Schema:** Documents in a same collection can have different attributes. Useful when data has no rigid structure.
2. **Natural Data Representation:** Data is stored in JSON-like format which most applications use.
3. **Fast Data Retrieval:** Related information can be stored together in one document, reducing the need for joins.

## Real-World Use Cases

| Scenario           | Why document databases?                                   |
| ------------------ | --------------------------------------------------------- |
| E-commerce         | Products have different attributes and nested details.    |
| Social media       | Posts can contain text, images, comments and metadata.    |
