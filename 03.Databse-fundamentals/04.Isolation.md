# Isolation

- Isolation means concurrent transactions should not interfere with each other.
- Even when multiple transactions run simultaneously, they should not see each other's incomplete or conflicting changes.

## Problems Isolation Prevents

### A. Dirty Read

- Reading data that another transaction has modified but not yet committed.
- Reading uncommitted data.

Example:
1. Transaction A changes balance from ₹1,000 to ₹500.
2. Transaction B reads the new balance (₹500).
3. Transaction A rolls back.

Transaction B has read a value that was never actually committed.

### B. Non-Repeatable Read

- Reading the same row twice within a transaction but getting different values.
-  Same row, different values

Example:
1. Transaction A reads balance = ₹1,000.
2. Transaction B updates balance to ₹500 and commits.
3. Transaction A reads the same account again = ₹500.

### C. Phantom Read

- Running the same query twice but getting a different set of rows.
- Same query, different set of rows

Example:

Transaction A executes:

```sql
SELECT * FROM employees WHERE salary > 50000;
```

- It gets 5 employees.
- Meanwhile, Transaction B inserts a new employee with a salary of ₹70,000 and commits.
- Transaction A runs the same query again and gets 6 employees.

##  Isolation Levels

Databases provide different isolation levels. Higher isolation generally means stronger protection against concurrency problems, but potentially lower performance.

| Isolation Level | Dirty Read | Non-Repeatable Read | Phantom Read |
|---|---|---|---|
| Read Uncommitted | Yes | Yes | Yes |
| Read Committed | No | Yes | Yes |
| Repeatable Read | No | No | Possible* |
| Serializable | No | No | No |

**Understand them intuitively:**

1. **Read Uncommitted:** You can read even uncommitted changes. Weakest isolation.
2. **Read Committed:** You only read committed data. However, data can change between two reads.
3. **Repeatable Read:** Once you read a row, its value remains consistent within your transaction.
4. **Serializable:** Transactions behave as if they executed one after another. Strongest isolation.
