# Consistent Hashing

## Problem with traditional hashing

```text
Server = Hash(User ID) % Number of Servers
```
- We want all requests from a user to be handled by the same server.
- Most hashing functions use number of servers in calculation. But what happens when we add or remove a server? The calculation changes.

This creates problems:
- Requests may reach different servers than before.
- Cached data on the previous servers becomes less useful.
- Servers need to rebuild their caches.
- This can increase latency and load.
