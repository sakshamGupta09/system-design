# Load Balancing

- Load balancing distributes incoming requests across multiple servers so that no single server gets overloaded.
- NGiNX, HAProxy, AWS load balancers are few popular load balancers.

## What Problem Does It Solve?

When we scale horizontally, we add more servers. But we need to decide:

- Which server should handle each request?
- What happens if a server crashes?
- How do we prevent one server from getting too much traffic?

## How Does It Work?

1. A user visits `example.com`.
2. DNS gave back an IP which is of a Load Balancer and directs the user to the load balancer.
3. The load balancer selects a healthy server.
4. The server processes the request and returns the response.

```text
          Users
             |
             v
       Load Balancer
        /    |    \
       v     v     v
   Server 1 Server 2 Server 3
```

## Key Benefits

- **Traffic distribution:** Spreads requests across servers.
- **High availability:** Stops sending traffic to failed servers.
- **Easy scaling:** New servers can be added to handle more traffic.
- **Zero-downtime deployments:** Traffic can be switched to new servers running new code changes without stopping the application.

### Health Checks

- The load balancer regularly checks whether servers are working.
- If a server fails, it stops sending requests to it. When the server recovers, it can receive traffic again.

## Types of Load Balancers

- **Layer 4:** Routes traffic using IP addresses and ports. It does not inspect HTTP URLs and request metadata. Extremely fast as no processing is done here. It cannot make intelligent routing decisions based on the request.
- **Layer 7:** Understands HTTP requests and can route based on URLs, headers, and cookies. Example all `/api` requests should go to API server. `/images` requests should go to images server. Requests with a cookie `beta = true` should go to a beta server.

**Example:** A Layer 7 load balancer can send `/api/*` requests to API servers and `/images/*` requests to image servers.

## What If the Load Balancer Fails?

- A single load balancer can become a single point of failure.
- **Solution:** Use multiple load balancers so another can take over or continue handling traffic if one fails.
