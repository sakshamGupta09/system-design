# Load Balancing

- Load balancing distributes incoming requests across multiple servers so that no single server gets overloaded.
- NGiNX, HAProxy, AWS load balancers are few popular load balancers.

## Problem

When we scale horizontally, we add more servers. But we need to decide:

- Which server should handle each request?
- What happens if a server crashes?
- How do we prevent one server from getting too much traffic?

## How Does It Work

1. A user visits `example.com`.
2. DNS gave back an IP which is of a Load Balancer and directs the user to the load balancer.
3. The load balancer selects a healthy server.
4. The server processes the request and returns the response.

## Health Checks

- The load balancer regularly checks whether servers are working.
- If a server fails, it stops sending requests to it. When the server recovers, it can receive traffic again.

## What If the Load Balancer Fails?

- A single load balancer can become a single point of failure.
- Use multiple load balancers.
