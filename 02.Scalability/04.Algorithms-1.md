# Load balancing algorithms

- Distribute incoming traffic so that no single server is overloaded.
- How does a LB decides which server will handle the next request? We need a rule.

## Round Robbin (RR)

- Give each server a turn, one after another, and repeat.

```text
Request:  R1  R2  R3  R4  R5  R6  R7  R8  R9
Server:    A   B   C   A   B   C   A   B   C
```

### Pros

- Simple and easy to understand and implement.
- Fair distribution. Each server handles equal proportion of requests. Works well when servers have similar capacity and requests have roughly similar processing costs.

### Cons

- Ignores server capacity: A powerful server with better hardware and a weak server receive the same number of requests.
- Ignores current load: A busy server may receive another request even when another server is idle.
- Ignores request complexity: One request may take milliseconds while another takes several seconds.
