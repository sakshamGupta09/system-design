# Problem

- Distributed databases need to communicate with each other over a network so that they all have same state and latest information.
- But what happens when the communication breaks? This is called a **Network Partition**.

We have two choices:
1. Stop accepting requests until communication is restored.
2. Continue accepting requests, even though they cannot synchronize their data.

## CAP Properties

| Property | Meaning |
|---|---|
| **Consistency (C)** | Every read gets the latest successfully written value. |
| **Availability (A)** | Every request to a functioning node receives a response, even if that response might contain old data. |
| **Partition Tolerance (P)** | The system continues operating despite network communication failures between database servers. |

## What happens during a network partition

Due to network failure DB servers are not able to communicate with each other. How should a system work -

## 1. Choose CP — Consistency + Partition Tolerance

Suppose a user has ₹10,000 in their bank account. They withdraw ₹2,000 using Database A. Database A cannot communicate with Database B. To prevent Database B from returning an outdated balance of ₹10,000, the system may reject or block requests that cannot be safely processed.

- Database A can process safe operations.
- Database B may reject or block reads and writes. Some requests become unavailable.
- The system avoids returning potentially outdated data.

**Example** Banking transactions

## 2. Choose AP — Availability + Partition Tolerance

A user updates their profile name on Database A. The network is broken, so Database B doesn't know about this update. Instead of rejecting requests, Database B continues serving users using its existing data.

- Both databases continue responding.
- Database A has the updated information.
- Database B might return outdated information.
- The databases synchronize when communication is restored.

**Example** Social media applications where temporarily seeing an outdated profile or follower count is generally acceptable.
