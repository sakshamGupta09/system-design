# DB Design

## Access Patterns

- Create a short URL.
- Fetch the original URL using short code.
- Fetch all URLs created by a user by ID for analytics.

## SQL vs NoSQL

- First big decision is SQL vs NoSQL. First consider the access patterns.
- **Use SQL** if data is structured, has a well defined schema. ACID transactions: You need reliable transactions and strong consistency. Harder to do horizontal scaling.
- **Use NoSQL** Ff data is nested and flexibility is needed. Easy horizontal scaling from day 1. Fast key value lookups.
- I would consider DynamoDB because URL redirection is a read-heavy workload with a simple key-based access pattern. DynamoDB provides managed horizontal scaling and high read throughput.
