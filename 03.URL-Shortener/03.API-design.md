# API Design Template

1. Start from the user intent. What are the users trying to do?
2. Users want to shorten their URLs, visit the original URL and view analytics.
3. Create endpoints to enable users to do these activities. 

## Create a short URL

- `POST /api/shorten`
- POST because we are creating a new resource.
- Request body `{ long_url : "", alias:"" }`.
- `long_url` is required and should be a valid URL.
- `alias` is optional because usually people just want to shorten the URL. Certain group of people like marketing might want to use custom aliases like `summer-sale`.

```json
{
   "shortUrl":"short.url/abc",
   "longUrl":"original_long_url",
   "createdAt":"",
   "expiresAt":""
}
```
